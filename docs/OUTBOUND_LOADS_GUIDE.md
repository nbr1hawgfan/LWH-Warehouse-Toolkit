# Outbound Loads / BOL — floor guide

1. **New load** → pick the **Warehouse**, then the **Sub-customer**.
2. Fill in **Carrier, Trailer #, Seal #**, Bill To Ref #, PRO #, appointment.
3. **Ship from / Ship to / Bill to** — start typing a name; tap a saved address to fill it.
4. **Order lines** — pick the item (only this customer's items show), choose
   *Number of pallets*, *Number of units* or *Specific pallet IDs*, add a PO if needed, **Add line**.
5. **Scan pallets** — tap the yellow bar (it turns green), then scan each pallet tag
   (LWH ID or Customer ID). Or tap **Use camera**.
   - Green = added. **Red = NOT added** — read the reason on the screen.
   - "Not found in inventory" or "different warehouse" → get a manager for the override button.
6. When every line is complete, **Close load**. The BOL prints. (Lines short? A manager approves shipping short.)
7. The office uses **Records → Closed — not in WMS yet** to re-enter each load
   (WMS entry sheet has a barcode for every pallet), then **Mark entered in WMS**.

If the hotspot drops, keep loading — everything is saved on the device and
sends itself when the connection is back. Don't clear the browser on that device
until the load shows **✓ Saved to records**.
